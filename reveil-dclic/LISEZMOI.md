# Le Réveil · DCLIC HLM

Présentation animée en 16:9 pour la réunion des militants. Elle fonctionne
hors ligne, sans Internet.

## Ouvrir la présentation

1. Copiez tout le dossier `reveil-dclic` sur l'ordinateur de projection.
2. Double-cliquez sur `index.html`. Elle s'ouvre dans Chrome, Edge ou Firefox.
3. Appuyez sur **F** pour passer en plein écran.
4. Appuyez sur **Espace** pour lancer le clip. À la fin du clip, la carte
   s'affiche toute seule.

## Touches

| Touche | Action |
| --- | --- |
| Espace | Lancer le clip, le mettre en pause, puis avancer sur la carte |
| Flèche droite / gauche | Avancer / reculer |
| F | Plein écran (Échap pour sortir) |
| R | Relancer le clip depuis le début |
| C | Aller directement à la carte |
| H | Afficher / masquer l'aide |

Sur la diapo 7 (le maillage), un premier appui sur la flèche droite fait
passer de « Avant » à « Maintenant ».

Pour répéter une diapo précise, ajoutez `?carte=4` à la fin de l'adresse dans
le navigateur (remplacez 4 par le numéro de la diapo).

## Remplacer le logo

Remplacez le fichier `logo-dclic.png` par votre nouveau logo, en gardant
exactement le même nom. Si le fichier manque, le texte « DCLIC HLM »
s'affiche à la place.

## Modifier un texte

1. Ouvrez `contenu.js` avec le Bloc-notes (clic droit, Ouvrir avec).
2. Changez seulement le texte entre guillemets `"..."`.
3. Enregistrez, puis appuyez sur F5 dans le navigateur.

Mettez des mots entre astérisques pour les afficher en bleu clair :
`"c'est *notre quartier*, pas un parti."`

## Modifier la carte

La carte est schématique. Les quartiers, leur position, le lieu de l'AG et
le quartier du candidat se règlent dans `quartiers.js`. Les explications se
trouvent en haut de ce fichier.
